# Ray normal square-root reuse regression

Copy this directory to repository tests/ray_normal_reuse only after integrating the reviewed patch. Run tests/ray_normal_reuse/run.sh and then run.sh --sanitize. SOURCE_DIR optionally selects an absolute source directory containing collide.c and collide.h. CC defaults to cc; TMPDIR defaults to results under this test directory. Every output is retained in a unique subdirectory. No game/target/emulator build or deletion is performed.

The generator reads live complete collide_obj_ray, dot3, to_local, to_world_dir, point_local and collide_matrix definitions, with current public types. It strictly requires exactly one reviewed reuse block and absence of the old block, reconstructs baseline by reversing only that block, and asserts transforming the extracted reference back matches the candidate. A changed block fails closed and needs review, not a frozen fallback. Source/test hashes are recorded and verified unchanged after execution.

Normal O2 and sanitized O1 modes each cover 99,840 finite representative sphere/box ray cases, bitwise t/normal and return equality, miss sentinels, inside/surface/outside, threshold edges, zero and near-parallel directions, translated/rotated/off-center objects and clipping limits. Math wrappers count 47,190 baseline versus 19,670 candidate sqrtf calls in this fixture, reducing 3 to 1 in 13,760 changed-branch cases. Real target assembly confirms that the accepted compiler also emits the reduction; see the private target report, not these host counts, for that evidence.

Limitations: narrow brace extractor; common current math helpers are not independent historical oracles; no full scene or runtime acceptance; no workload/FPS implication. The source guard is deliberately narrow. Nonfinite/malformed inputs, dynamic rounding/environment changes and math interposition are excluded. ASan/UBSan default detect_leaks=0 (LSan restricted under ptrace); the path allocates nothing. Build flags use -fno-builtin as nxdk does. No arbitrary optimization/fast-math flags are added.
